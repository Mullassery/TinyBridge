Open-source macOS Linux development substrate. Zero-config environments, instant SSH access, automatic resource management.

## Guidelines

- **Emphasize value, not technology**: Users care about "Linux environments on macOS" not "written in Rust + Swift"
- **Keep it short**: GitHub truncates at ~160 characters, so lead with the core benefit
- **No technical implementation details**: Rust, Swift, VZ Framework, etc. are internal—users don't need to know
- **Action-oriented**: "Zero-config", "Instant SSH", "Automatic resource management" show what users get

To update this in GitHub:
1. Go to repository Settings
2. Click "General" 
3. Scroll to "About" section
4. Fill in Description field with the text above
5. Add the topics listed
6. Save

This keeps the About section focused on user benefits, not technical stack.
